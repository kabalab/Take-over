Build a free multiplayer Coup web game. Front‑end is HTML/CSS/JS using Canvas for the UI. Back‑end is Node.js + Express with Socket.IO as the authoritative real‑time game server. Use SQLite for storage with custom username/password auth (no email), passwords hashed with bcrypt, sessions stored in cookies. Add optional friends list to let users join friends’ rooms more easily. Rooms use codes and exist only while at least one player is inside (delete room when empty). Support 2–10 players per room. Implement standard Coup rules, with a 60‑second turn timer and a 30‑second challenge window after actions. Server validates all actions, manages hidden state (cards/deck), and broadcasts only public info to players. Deploy for free: front‑end on Vercel/Netlify, back‑end on Render, SQLite stored on server.
